# FAME/AC17 CP-ABE – Experimental Evaluation

This repository contains a modified Python implementation of the AC17 Ciphertext-Policy Attribute-Based Encryption (CP-ABE) scheme, based on the original [ABE repository](https://github.com/sagrawal87/ABE).

The code was adapted for the experimental evaluation conducted as part of a Master's thesis in Cryptography and Cybersecurity.

Modifications include:

- Benchmarking of Setup, Key Generation, Encryption, and Decryption.
- Evaluation of AND-based access policies with up to 100 attributes.
- Warm-up and repeated execution measurements.
- CSV export of experimental results.
- Decryption correctness verification.

The repository is intended for academic and research purposes.
